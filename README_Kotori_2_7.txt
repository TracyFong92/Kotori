Kotori 日本語學園 2.7 更新包
版本主題：Adventure UI 介面重設

更新內容
1. 以 Kotori 2.6 為基礎，保留原有 60 個單字、智能複習、自動難度、每日報告及錯題挑戰。
2. 學習地圖改為六個主要地區的簡潔 2 欄卡片版面。
3. 單字森林將今日智能複習及聆聽／句子挑戰移到頁面上方，不需滑到單字清單底部。
4. 單字卡整理成較精簡的卡片，發音及收藏功能保留。
5. 其他複習工具及紀錄收納到可展開的「更多學習工具及紀錄」。
6. 測驗畫面移除常駐離開按鈕，集中顯示題目、選項及下一題。
7. 保留 localStorage 主鍵 kotori-jp-v1，Service Worker 更新至 v27。

舊版功能保留
1. 整合原有 30 個單字及 2.5 新增的 30 個單字，共 60 個。
2. 智能複習會優先選取到期、未練習及較不熟悉的單字。
3. 依答題表現調整難度：日文辨義、中文配對、聽力辨認及應用理解。
4. 記錄每個單字的答題次數、正確次數、連續答對、熟練度及下次複習時間。
5. 新增學習報告室及錯題挑戰室。
6. 保留原有 XP、金幣、收藏、錯題、2.5 單字、發音、測驗及 PWA。

更新方式
1. 先下載並解壓縮 ZIP。
2. 開啟 kotori_pwa_project 資料夾。
3. 將資料夾內所有檔案及 icons 資料夾上傳至 GitHub Kotori Repository 根目錄。
4. 如 GitHub 詢問是否覆蓋，選擇覆蓋現有檔案；不要刪除 Repository。
5. Commit changes，等待 GitHub Pages 綠色剔號。
6. 在 iPhone Safari 開啟 https://tracyfong92.github.io/Kotori/，等待更新後重新開啟主畫面 App。

資料保留
- localStorage 主鍵維持 kotori-jp-v1。
- 不要清除 Safari 網站資料、不要重設 App 資料。
- 新增的 2.6 複習紀錄會儲存在同一部裝置。

注意
- 請先確認 XP、金幣及收藏仍在，再測試新功能。
- 如版本未更新，先在 Safari 重新載入網站；不要清除網站資料。
