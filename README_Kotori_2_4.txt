Kotori 日本語學園 2.4 更新包

本版本新增：單字森林每張單字卡均有 🔊 喇叭按鈕，按下即可播放日文讀音（使用裝置／瀏覽器內置日文語音）。

更新方法：
1. 解壓縮此 ZIP。
2. 將 kotori_pwa_project 資料夾內的所有檔案和 icons 資料夾內容，上傳到 GitHub 的 Kotori repository 根目錄。
3. 遇到同名檔案時選擇覆蓋；保留原有資料夾結構。
4. Commit changes，等待 GitHub Pages 部署成功。
5. iPhone 先用 Safari 開啟網站並重新整理，再開啟主畫面上的 Kotori。

重要：此更新保留原本 localStorage key（kotori-jp-v1），不會主動清除 XP、金幣、錯題或學習進度。請勿刪除網站資料或清除 App 儲存資料。

注意：語音由 iPhone／瀏覽器提供，實際聲線取決於裝置已安裝的日文語音。首次使用時請保持裝置音量開啟。
