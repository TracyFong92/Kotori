Kotori 日本語學園 2.5 更新包

版本主題：單字森林 2.0

本版本以 Kotori 2.4 為基礎，保留原有 PWA、五十音、舊版 30 個單字、文法、故事、漫畫、記憶補給站、XP、金幣及舊錯題功能。

新增內容：
1. 新增 30 個基礎日語單字，分為三組各 10 個：日常生活、動漫漫畫常見用語、JLPT N5 基礎詞彙。
2. 每個新單字提供假名讀音、中文意思、日文例句、例句假名及中文翻譯。
3. 每張新單字卡可分別播放單字及例句日語發音，沿用裝置內置日語語音。
4. 新增聽力單字測驗：聆聽讀音後選擇正確日文單字。
5. 新增例句理解測驗：閱讀日文句子後選擇正確中文意思。
6. 新單字分三區逐步開放，每區 10 個；單次測驗達 8/10 可解鎖下一區。
7. 新增單字成長紀錄：練習數、掌握數、答題次數、正確率及待複習單字。
8. 新單字答對累積 3 次即標記為「已掌握」；答錯會加入待複習清單，之後答對可移除。
9. 聽力及例句測驗各自每日首次達到 7/10，可獲得 5 XP + 2 金幣。

更新方法（GitHub Pages）：
1. 下載並解壓縮 ZIP。
2. 打開 kotori_pwa_project 資料夾。
3. 將資料夾內的 index.html、sw.js、manifest.webmanifest、README，以及 icons 資料夾上傳至 GitHub 的 Kotori repository 根目錄。
4. 遇到同名檔案時選擇覆蓋，保留 icons 資料夾結構。
5. Commit changes，等待 GitHub Pages 部署成功（綠色剔號）。
6. iPhone 先用 Safari 開啟 https://tracyfong92.github.io/Kotori/ 並重新整理，再開啟主畫面上的 Kotori。

重要資料保護：
- localStorage key 維持 kotori-jp-v1，與 2.4 相同。
- 不會主動清除 XP、金幣、收藏、舊錯題、每日紀錄或既有學習進度。
- 新增的 2.5 單字進度會存放在同一份本機學習資料中。
- 請勿為了更新而刪除 App、清除 Safari 網站資料或清空本機儲存空間。

語音注意事項：日語發音使用 iPhone／瀏覽器提供的 Speech Synthesis。聲線和可用語音會因裝置設定而異；播放時請確保裝置音量開啟。
