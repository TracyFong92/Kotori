Kotori 日本語學園 2.8.2 修正版
版本主題：章節學習流程簡化

本版本修正：
1. 首頁及學習地圖以外的學習內容頁面維持專注畫面；不更改 2.8.1 已確認正常的固定畫面設定。
2. 五十音花園章節直接進入學習，不再先顯示「學習課程／挑戰」兩個選項。
3. 章節模式下，依次瀏覽假名；到達最後一個假名並按「完成學習・開始測驗」時，自動進入 10 題測驗。
4. 測驗答對至少 7/10 題，會自動完成本章並解鎖下一章；未達標可重新挑戰。
5. 保留原有 XP、金幣、收藏、錯題、單字、複習進度及章節完成紀錄。

重要：
- localStorage 主鍵仍為 kotori-jp-v1，不需要清除資料或重新安裝。
- Service Worker cache 已更新為 kotori-academy-v28-2。
- 上傳時請覆蓋 GitHub repository 根目錄內的檔案。
